🔬 EBSD Analyzer

Análise de dados de EBSD direto no navegador — tamanho de grão, desorientação, textura, KAM e figuras prontas para publicação.

▶ Abrir o aplicativo O aplicativo (Streamlit) roda em /port/5000. Se o botão não abrir, aguarde alguns segundos e recarregue.
⚠️ Dados de exemplo são SINTÉTICOS (gerados por computador). Servem apenas para demonstrar o aplicativo — não são dados experimentais reais e não devem ser usados como resultado de pesquisa.

Como usar (teste em 4 passos)

  1. Clique em “Abrir o aplicativo” acima.
  2. Na barra lateral, clique em Browse files.
  3. Envie o exemplo mínimo sample_data/exemplo_graos.csv (dados por grão) — as análises são preenchidas automaticamente.
  4. Para testar a segmentação automática de grãos a partir de pixels, envie sample_data/exemplo_pixels.ctf.

O que o app faz

  • Distribuição de tamanho de grão (log-normal, CDF, normalidade)
  • Histograma de desorientação (LAGB/HAGB, curva de Mackenzie)
  • Resumo de textura e frações de orientações ideais
  • Detecção de outliers (IQR / Z-score)
  • KAM e estimativa de densidade de discordâncias (GND)
  • Visualizações IPF (mapa, triângulo, cubo 3D) e figuras de polo
  • Exportação das figuras em PNG / SVG / PDF (300 dpi)

Arquivos e formatos aceitos

FormatoExtensãoOrigem / nível
CTF.ctfOxford / HKL — dados por pixel
BCF.bcfBruker Esprit (se falhar, exporte como CSV)
CSV / TXT.csv, .txtOIM, AztecCrystal, MTEX — dados por grão

Se os nomes das colunas forem diferentes, use o painel Column mapping dentro do app.

Quer rodar no seu computador?

Instale o Python, depois:

pip install -r requirements.txt
streamlit run app.py
