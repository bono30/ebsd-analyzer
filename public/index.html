EBSD Analyzer

Analise de dados de EBSD (Electron Backscatter Diffraction) direto no navegador.

Abrir o aplicativo

O aplicativo (Streamlit) roda em /port/5000. Se nao abrir de imediato, aguarde alguns segundos e recarregue a pagina.

O que o aplicativo faz

  • Distribuicao de tamanho de grao (histograma log-normal, CDF, teste de normalidade)
  • Histograma de desorientacao (LAGB/HAGB, curva de Mackenzie)
  • Resumo de textura e fracoes de orientacoes ideais
  • Deteccao de outliers (IQR / Z-score)
  • KAM e estimativa de densidade de discordancias (GND)
  • Mapas IPF (triangulo, cubo 3D), figuras de polo e exportacao em PNG / SVG / PDF

Arquivos aceitos

FormatoExtensaoOrigem / nivel
CSV / TXT.csv, .txtOIM, AztecCrystal, MTEX - dados por grao
CTF.ctfOxford / HKL - dados por pixel
BCF.bcfBruker Esprit (se falhar, exporte como CSV)

Se os nomes das colunas forem diferentes, use o painel Column mapping dentro do aplicativo.

Teste minimo

  1. Clique em Abrir o aplicativo.
  2. Na barra lateral, clique em Browse files.
  3. Envie sample_data/exemplo_graos.csv (dados por grao).
  4. Para testar a segmentacao automatica, envie sample_data/exemplo_pixels.ctf (dados por pixel).
Atencao: os arquivos de exemplo sao sinteticos (gerados por computador) apenas para demonstracao. Nao sao dados experimentais reais e nao devem ser usados como resultado de pesquisa.

Privacidade

Esta e uma demonstracao publica. Os arquivos enviados sao processados no servidor (em memoria) e nao sao armazenados permanentemente, mas nao envie dados confidenciais ou ainda nao publicados para esta instancia publica.

Arquivos do repositorio necessarios

  • app.py - aplicativo principal (ponto de entrada)
  • requirements.txt - dependencias Python
  • file_readers.py - leitura de CSV / CTF / BCF
  • ctf_processing.py - segmentacao de graos, KAM, estatisticas
  • ipf_plots.py - graficos IPF (triangulo, cubo 3D)
  • pf_plots.py - figuras de polo e mapa IPF 2D
  • sample_data/ - dados de exemplo (exemplo_graos.csv, exemplo_pixels.ctf)

Atualizacao manual (editar e republicar)

Apos editar os arquivos, atualize o repositorio. O deploy e refeito a partir do novo commit:

git add .
git commit -m "descreva a mudanca"
git push origin main
